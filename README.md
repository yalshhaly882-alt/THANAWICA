# منصة تعليمية (Next.js + Firebase + Vercel)

## 1) إنشاء قاعدة بيانات Firebase
1. ادخل https://console.firebase.google.com وسجل بحساب جوجل.
2. **Add project** ← اكتب اسم المشروع ← كمّل (تقدر تقفل Google Analytics).
3. من القايمة الجانبية: **Build ← Firestore Database ← Create database**.
   - اختار **Production mode** وأقرب منطقة (مثلاً `eur3` أو `europe-west`).
4. من تبويب **Rules** امسح المحتوى والصق محتوى ملف `firestore.rules` ثم **Publish**.
   القواعد بتمنع المتصفح تمامًا، وكل التعامل بيتم من السيرفر.
5. **مفتاح السيرفر:** ⚙️ Project settings ← **Service accounts** ← **Generate new private key** ← هينزل ملف JSON. منه هتاخد:
   `project_id` و`client_email` و`private_key`. الملف ده سري ومتنشروش ولا ترفعه على GitHub.
6. **إعدادات الإشعارات (اختياري لكن مطلوب للإشعارات):**
   - ⚙️ Project settings ← General ← Your apps ← أيقونة الويب `</>` ← سجّل تطبيق ويب ← انسخ القيم (apiKey, authDomain, projectId, messagingSenderId, appId).
   - تبويب **Cloud Messaging** ← **Web Push certificates** ← **Generate key pair** ← انسخ الـ Key (ده الـ VAPID).

> مفيش حاجة تعملها في الجداول: المنصة بتنشئ الـ collections لوحدها أول ما تضيف بيانات من لوحة التحكم.

## 2) التشغيل على جهازك
```bash
npm install
cp .env.example .env.local     # وبعدين املا القيم
npm run dev                    # افتح http://localhost:3000  و  /admin
```
القيم:
| المتغير | من فين |
|---|---|
| `FIREBASE_PROJECT_ID` / `FIREBASE_CLIENT_EMAIL` / `FIREBASE_PRIVATE_KEY` | ملف الـ JSON (الـ private_key بين علامتي تنصيص و`\n` زي ما هي) |
| `SESSION_SECRET` | أي نص عشوائي 32+ حرف |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | بيانات دخولك كمالك (غيّر الباسورد من اللوحة بعد أول دخول) |
| `NEXT_PUBLIC_FIREBASE_*` و`NEXT_PUBLIC_FIREBASE_VAPID_KEY` | إعدادات الويب والـ VAPID من الخطوة 6 |
| `NEXT_PUBLIC_SITE_NAME` / `NEXT_PUBLIC_ADMIN_TELEGRAM` | اسم المنصة ويوزر تليجرام الأدمن بدون @ |

## 3) الرفع على GitHub
1. اعمل حساب على https://github.com ← **New repository** ← اسم مثل `edu-platform` ← **Private** ← Create (من غير README).
2. من مجلد المشروع:
```bash
git init
git add .
git commit -m "first version"
git branch -M main
git remote add origin https://github.com/USERNAME/edu-platform.git
git push -u origin main
```
(`.gitignore` بيمنع رفع `.env.local` و`node_modules`. اتأكد إن مفيش ملف JSON بتاع Firebase جوه المجلد.)

## 4) النشر على Vercel
1. ادخل https://vercel.com ← Login with GitHub.
2. **Add New ← Project** ← اختار الريبو ← Import.
3. قبل Deploy افتح **Environment Variables** وأضف كل متغيرات الجدول اللي فوق بنفس الأسماء.
   - `FIREBASE_PRIVATE_KEY`: الصقها كاملة (Vercel بيقبلها بالـ `\n` أو بأسطر حقيقية).
4. **Deploy**. هيديك رابط `https://اسم-المشروع.vercel.app`.
5. افتح `/admin` وسجل دخول. أي تعديل تعمله وتعمله `git push` بيتنشر لوحده.
6. لو ضفت متغيرات بعد النشر: Settings ← Environment Variables ← Redeploy.

## 5) أول استخدام
1. `/admin` ← أضف بالترتيب: **الشعب ← السنين ← المواد ← المدرسين ← الفصول ← المحاضرات** (حط روابط الفيديوهات والملفات) ← **الامتحانات**.
2. تبويب **المشتركين والأكواد** ← ولّد أكواد تجربة (ساعة) أو شهرية.
3. الطالب يدخل على `/login` بالكود.

## إزاي الإشعارات بتشتغل
- لما تضيف **محاضرة جديدة** من اللوحة (وعلامة "إرسال إشعار" شغالة) بيحصل حاجتين: إشعار داخل المنصة (الجرس 🔔) + إشعار على جهاز الطالب (Firebase Cloud Messaging).
- الطالب بيفعّل إشعارات الجهاز من **حسابي ← إعدادات الإشعارات**، وبيقفل أي مادة أو مدرس مايحبش يوصله منهم.
- بتوصل بس للطلاب في نفس الشعبة واشتراكهم شغال.
- على الآيفون: لازم الطالب يضيف الموقع للشاشة الرئيسية الأول.
- الإشعارات بتحتاج **HTTPS**، فبتشتغل على Vercel مش على localhost.

## لوحة المعلومات
أول تبويب في `/admin`: عدد المشتركين النشطين والمنتهيين وغير المستخدمين، تفعيلات وامتحانات آخر 14 يوم، الطلاب حسب الشعبة، الاشتراكات اللي هتخلص قريب، وعدد المحتوى.

## إزاي بيشتغل
- **جهاز واحد:** أول جهاز يدخل بالكود بيتسجل، وأي جهاز تاني بيترفض. "تغيير الجهاز" من اللوحة.
- **الدخول مرة واحدة:** الجلسة بتفضل لحد ما مدة الكود تخلص، وبعدها تظهر "اشتراكك انتهى".
- **مدة الكود:** بتبدأ من أول دخول (تجربة = ساعة، شهري = 30 يوم) والتحقق في السيرفر.
- **الامتحانات:** التصحيح في السيرفر، والإجابات الصحيحة مبتتبعتش إلا بعد التسليم.
- **الأمان:** كلمات المرور متشفرة (scrypt)، والجلسات موقعة، وفيه قفل مؤقت بعد المحاولات الغلط.

## حدود لازم تعرفها
- قفل الجهاز بيمنع مشاركة الكود العادية لكن مش تسجيل الشاشة. لحماية أقوى استخدم استضافة فيديو محمية (Bunny Stream / Vimeo).
- لو الطالب مسح بيانات المتصفح هيتعامل معاه كجهاز جديد، وتفتحله من "تغيير الجهاز".
- **لسه مش موجود:** التحقق بخطوتين للأدمن.

## الاسم والدعم الفني والأسعار
- **اسم المنصة:** بيتغير من المتغير `NEXT_PUBLIC_SITE_NAME` (بيظهر في الهيدر والفوتر وكل الصفحات).
- **الدعم الفني (زي DR Youssef / Dr. Sara):** من `/admin` ← تبويب **الدعم الفني** ← أضف الاسم ويوزر تليجرام. الطالب لما يضغط على الاسم بيفتحله تليجرام على حسابه. بيظهروا في صفحة `/subscribe`.
- **الأسعار:** تبويب **خطط الاشتراك** ← أضف الخطة والسعر (مثال: تالتة ثانوي 200). بتظهر في صفحة `/subscribe` مع خطوات الاشتراك.
- **كود الطالب باسمه:** في تبويب **المشتركين والأكواد** ← "ابحث عن كود طالب" ← اكتب الاسم يظهرلك الكود. وعند التوليد اكتب اسم الطالب فيتسجل مع الكود.
